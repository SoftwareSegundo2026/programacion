FastAPI Chinook API

v1.0.0

API REST construida con FastAPI sobre la base de datos Chinook (tienda de música digital). CRUD completo de artistas, álbumes, géneros y pistas musicales, con autenticación JWT, activity logging y servicio de imágenes.
